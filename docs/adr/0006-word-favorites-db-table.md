# 单词收藏夹引入 DB 表，窄幅修正 ADR-0005

单词收藏夹与搭配收藏夹对等：用户主动收藏单词、可移除，是持久的用户状态，必须落库。这推翻了 ADR-0005「不引入数据库表」的字面结论——那条 ADR 当初挡住的是**自测 / 掌握态 / SRS 排期**三类重状态，理由是背单词页是纯浏览参考。收藏是第四类、最轻的状态，只记「是否收藏 + 收藏时间」，与那三类性质不同。

## 窄幅放行，不滑坡

只放行「收藏」这一类用户状态。新增 `word_notebook (word_id PK, added_at)` 表，与现有 `collocation_notebook` 完全对称（字段、生命周期一致）。**自测、掌握态、SRS 排期仍维持禁止**——它们一旦引入会改变背单词页「纯浏览参考」的定位，且需要排序/抽题/计分等重逻辑，不在本次范围。本 ADR 只为收藏开一个最小口子，不重开 ADR-0005 的整体结论。

## 按单词 id 跨词表去重

`words.json` 以「词表 × 单词」为行，同一单词在多份词表里各占一行（ADR-0005）。收藏表以 **word_id 为主键**（`INSERT OR IGNORE`），故同一单词在一个词表 tab 下被收藏即视为该词已收藏，收藏页里每个词只出现一次。收藏对象是「词本身」，不是「某词表里的那一行」。展示时按 word_id 取任意一行——同一 word_id 的多行数据字段完全一致（已核对），无歧义。

## 命名

内部表名沿用 `word_notebook`（与 `collocation_notebook` 对称、零迁移成本）；「收藏夹」只体现在 UI 标题与 CONTEXT 术语，与术语表里的「错题本」（答错题 → 复测）严格区分。
